J5 サーボ制御シミュレータ

FX5UC-64MT/D ＋ シンプルモーション FX5-40SSC-G（U1）＋ MR-J5-40G（CC-Link IE TSN）でボールねじ軸を動かす想定です。GX Works3 のニーモニックでラダーを書き換えて書き込むと、PLC のスキャン → シンプルモーション → サーボ → 機械の動きが変わります。学習用の簡易モデルで、実機の値ではありません。

原点復帰は近点ドグ式・負方向。ドグ後端（0〜10 mm のドグの 0 mm 側）で止まり、そこを原点アドレス 0 にします（ゼロ点信号は省略）。加減速時間は 0 から速度制限値までの時間です。

    

    

      
バッファメモリの割り付け（軸 1）

      
デバイス項目内容

      
番号は RD77・FX5-SSC 系の取扱説明書の項目を手がかりにした、このシミュレータでの割り付けです。実機のアドレスは FX5-40SSC-G のマニュアルで必ず確かめてください。Md.23 のエラー番号もこのシミュレータ独自です。

    

  


  

    

      
動かし方

      

        
    
          
  1. サンプル 1 が書込み済み・RUN の状態で始まります。サーボ ON スイッチ（X5）は ON です。
    2. 
          
  2. JOG+（X3）を押している間だけ軸が動きます。離すと減速して止まります。
    3. 
          
  3. 原点復帰（X2）でドグを探し、ドグ後端で止まって Md.20 が 0 になります。
    4. 
          
  4. 起動（X0）で位置決めデータ No.1（ABS 300 mm）へ動きます。
    5. 
          
  5. ニーモニックを書き換えて「変換＋書込み」（F4 または Ctrl+Enter）。RUN 中書込みとして、そのまま動作が変わります。
    6. 
        

        
    
          
  • シンプルモーションは Cd.184（位置決め始動）などの立上りで動きます。同じ信号を 2 か所で OUT すると後ろが勝ちます（サンプル 3）。
    • 
          
  • 位置決め完了（Md.31 b15）は始動で OFF になります。始動した直後のスキャンではまだ前の値なので、始動完了（b14）と組み合わせます。
    • 
          
  • サーボ OFF 中の始動、ストロークエンド到達、サーボ異常はエラー（Md.31 b13）になります。Cd.5 に 1 を書くとリセットします。
    • 
          
  • スキャンは 1 ms 固定、サーボの制御周期は 50 µs、通信の遅れは省略しています。
