J5 サーボ制御シミュレータ

FX5UC-64MT/D の内蔵 Ethernet から CC-Link IE フィールドネットワーク Basic で MR-J5-40G を直結し、位置決めモード（ポイントテーブル方式）でボールねじ軸を動かす想定です。GX Works3 のニーモニックでラダーを書き換えて書き込むと、コントロールワードとステータスワードのやり取りが変わり、機械の動きが変わります。学習用の簡易モデルで、実機の値ではありません。

サイクリックデータの割り付け（局番 1）

      
PLCリンク内容

      
GX Works3 の CC-Link IEF Basic 設定で RWw を D2000〜、RWr を D1000〜 にリフレッシュした想定です。RWw・RWr とオブジェクトの対応、JOG の割り当て（コントロールワード b4/b5）、アラーム番号の形はこのシミュレータでの例です。実機は MR-J5-G のユーザーズマニュアル（CC-Link IE フィールドネットワーク Basic 編）と、サーボ・PLC の設定で必ず確かめてください。

    

  


  

    

      
動かし方

      

        
    
          
  1. サンプル 1 が書込み済み・RUN で始まります。サーボ ON スイッチ（X5）が ON なので、ステータスワードが 0250h → 0231h → 0233h → 0237h と進み、サーボ ON になります。
    2. 
          
  2. JOG+（X3）を押すとモードが jg に切り替わり、押している間だけ動きます。
    3. 
          
  3. 原点復帰（X2）でモードを hm に切り替えて始動します。ドグ後端で止まり、位置実際値が 0 になります。
    4. 
          
  4. 起動（X0）でポイントテーブル No.1（300 mm）へ動きます。
    5. 
          
  5. ニーモニックを書き換えて「変換＋書込み」（F4 か Ctrl+Enter）。RUN 中書込みとして、そのまま動作が変わります。
    6. 
        

        
    
          
  • コントロールワードは CiA402 の状態遷移どおりに 6 → 7 → 15 と段階を踏みます。いきなり 15 を書いても ON しません（サンプル 3）。
    • 
          
  • 始動（b4）は「モード表示 6061h が切り替わったこと」を確かめてから立ち上げます。
    • 
          
  • 始動の受付（ステータス b12）を見たら b4 を下げ、到達（b10）で完了を判断します。
    • 
          
  • RWw・RWr はリンク周期（初期 5 ms）ごとにしか届きません。書いた次のスキャンでは、まだ結果が返っていません。
