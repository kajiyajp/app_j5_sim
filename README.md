# app_j5_sim — J5 サーボ制御シミュレータ

FX5UC-64MT/D の内蔵 Ethernet から CC-Link IE フィールドネットワーク Basic で MR-J5-40G を直結し、位置決めモード（ポイントテーブル方式）でボールねじ軸を動かす様子をブラウザで試す、学習用のシミュレータです。

GX Works3 のニーモニックでラダーを書き換えて書き込むと、コントロールワードとステータスワードのやり取りが変わり、機械の動きが変わります。

> **非公式の学習用ツールです。** 三菱電機株式会社とは関係がなく、同社が作ったり、認めたり、サポートしたりしているものではありません。数値は実機の値ではない簡易モデルです。

> **English:** An unofficial browser simulator for learning how a PLC (FX5UC) drives an MR-J5-G servo over CC-Link IE Field Network Basic. The UI is available in English: **https://kajiyajp.github.io/app_j5_sim/?lang=en** (or use the 日本語 / EN switch in the top bar). Not affiliated with Mitsubishi Electric. Do not write its ladder or settings to real equipment.

## 使い方

公開ページのほか、ダウンロードした `index.html` をブラウザ（Chrome・Edge・Firefox・Safari）で開くだけでも動きます。インストールやビルド、サーバーは要りません。

1. サンプル 1 が書込み済み・RUN の状態で始まります。サーボ ON スイッチ（X5）が ON なので、ステータスワードが 0250h → 0231h → 0233h → 0237h と進んでサーボ ON になります。
2. JOG+（X3）・JOG−（X4）を押している間だけ動きます。
3. 原点復帰（X2）でドグ後端に止まり、位置実際値が 0 になります。
4. 起動（X0）でポイントテーブル No.1（300 mm）へ動きます。
5. ニーモニックを書き換えて「変換＋書込み」（F4 か Ctrl+Enter）。RUN 中書込みとして、そのまま動作が変わります。

### 上のバーの切り替え

| 切り替え | 内容 |
|---|---|
| No. 指定: ラダー ／ セレクタ | **ラダー**: ラダーの `MOV K1 D2002` で No. を決める。**セレクタ**: 操作盤のデジタルスイッチ（X10〜X13、BCD）で No.1〜4 を選んで起動（X0）。0・5〜9 では始動しない |
| オーバーライド: OFF ／ ON | **ON**: 操作盤のロータリースイッチ（X14〜X17、16 進）で速度を 50〜150 % に変える（0〜A が 10 % 刻み、B〜F は 150 %）。位置決め・JOG・原点復帰のすべてに効き、運転中に回してもすぐ変わる |
| 日本語 ／ EN | 画面の文言、サンプルラダーのコメント、デバイスコメントの初期値、エラーメッセージを英語にする。切り替えるとページを読み込み直す（ラダー・レイアウト・コメントは保存済みなので消えない）。初めて開いたときはブラウザの言語に合わせる。URL に `?lang=en`・`?lang=ja` を付けても選べる |

切り替えると、その組み合わせのサンプル（下の表）を書き込み、操作盤とラダーをそろえます。エディタに自作のラダーがあるときは、置き換える前に確かめます。

## 画面

画面の上部には、バー（RUN/STOP・書込み・タイトル・切り替え）と、機械・操作盤を横に並べて固定しています（幅 1600px 以上・高さ 760px 以上の画面。下のペインだけがスクロールします）。タイトルをクリックすると、今のモードに合わせた説明が開きます。

その下のペインは、左上の ⠿ をドラッグして並べ替えられます。右上のボタンで幅（1/4・1/3・1/2・2/3・3/4・全幅）を変えたり、たたんだりできます。広い画面では 4 列、幅 1280px 以下は 2 列、960px 以下は 1 列に並びます。「レイアウトを戻す」で初期の並びに戻ります。

| ペイン | 内容 |
|---|---|
| 機械（上部に固定） | ボールねじ軸、テーブル、近点ドグ、ストロークエンド、位置・速度・偏差・トルク |
| 操作盤（上部に固定） | 押しボタン・切替スイッチ（X0〜X7。JOG− を左＝LSN 側、JOG+ を右＝LSP 側に配置）、ランプ（Y0〜Y3）、アンプの表示。セレクタ方式ではデジタルスイッチ、オーバーライド ON ではロータリースイッチも出る |
| 構成ブロック図 | スイッチ → ラダー → RWw → リンク → サーボ（状態遷移・制御モード・ポイントテーブル）→ 位置指令 → モータ、RWr で PLC に戻る経路。今の値と信号が流れている経路を表示 |
| ラダー | ニーモニックから描いたラダー図のモニタ。デバイスコメント付き。枠の右下をドラッグして高さを変えられる |
| 編集と資料 | タブ: ニーモニック、ポイントテーブル、割り付け、動かし方、デバイスコメント、使える命令、デバイスモニタ（プログラムで使うデバイスの現在値とコメント） |
| 波形 | タブ: タイミングチャート（ビットとワードの波形。トリガ、カーソル A/B と Δt、時間幅 0.5〜20 秒）、トレース（速度・偏差・トルク、直近 4 秒） |

### ラダー図の操作

| 操作 | 内容 |
|---|---|
| マウスを乗せる | 構成ブロック図で、同じデバイスの行をピンクに光らせて 0.4 秒周期で点滅 |
| クリック | 同じデバイスが次に出てくる場所へ飛ぶ（「2 / 5 か所目」のように表示。ビット指定は元のワードと同じとみなす） |
| ダブルクリック | デバイスコメントを編集 |
| Ctrl＋クリック（Mac は ⌘＋クリック） | 「割り付け」タブでそのワードの行を表示。割り付け表にないデバイス（X・Y・M など）はデバイスコメントを表示 |

## サンプル

| サンプル | 内容 |
|---|---|
| 1 手動操作 | サーボ ON（CiA402 の状態遷移を 6 → 7 → 15）、JOG、原点復帰、No.1 の始動 |
| 2 自動往復 | 工程番号 D100 で No.1 ↔ No.2 を往復。停止 X1 でサイクルを終えて止まる |
| 3 誤り例 | 状態を見ずにコントロールワードに 15 を書く。サーボ ON にならない |
| 4 セレクタ方式 | サンプル 1 の No. 指定を、デジタルスイッチから `BIN K1X10 D10` で読んだ値に置き換え。1〜4 のときだけ M32 が ON になり始動できる |
| 5 オーバーライド（ラダー方式） | サンプル 1 ＋ ロータリースイッチから `MOV K1X14 D11`・`* D11 K10 D12`・`+ D12 K50 D14` でオーバーライド率を求め、D2003 へ |
| 6 オーバーライド（セレクタ方式） | サンプル 4 ＋ サンプル 5 のオーバーライド |

サンプル 1〜4 は、オーバーライドを使わないので D2003 に 100（%）を書きます（前に書いた倍率が残らないように）。

## 想定している構成と割り付け

| PLC | リンク | 内容 |
|---|---|---|
| D2000 | RWw0 | 6040h コントロールワード |
| D2001 | RWw1 | 6060h 制御モード（-101 pt・-100 jg・6 hm） |
| D2002 | RWw2 | ポイントテーブル指定 |
| D2003 | RWw3 | オーバーライド %（0 は 100 % 扱い、上限 200 %） |
| D2004〜2005 | RWw4-5 | JOG 速度（µm/s） |
| D1000 | RWr0 | 6041h ステータスワード |
| D1001 | RWr1 | 6061h 制御モード表示 |
| D1002 | RWr2 | 完了ポイントテーブル No. |
| D1004〜1005 | RWr4-5 | 6064h 位置実際値（µm） |
| D1006〜1007 | RWr6-7 | 606Ch 速度実際値（µm/s） |
| D1008 | RWr8 | アラーム番号 |

操作盤の入力（PLC の X）:

| PLC | 内容 |
|---|---|
| X0〜X7 | 起動・停止・原点復帰・JOG+・JOG−・サーボ ON・異常リセット・非常停止 |
| X10〜X13 | デジタルスイッチ（TOSOKU 想定、BCD 1 桁）。重み 1・2・4・8。セレクタ方式のときだけ |
| X14〜X17 | ロータリースイッチ（TOSOKU 想定、16 進 1 桁）。重み 1・2・4・8。オーバーライド ON のときだけ |

RWw・RWr とオブジェクトの対応、JOG の割り当て（コントロールワード b4/b5）、RWw3 のオーバーライド、アラーム番号の形は**このシミュレータでの例**です。デジタルスイッチ・ロータリースイッチの型番や配線も、実機では確かめていません。実機は MR-J5-G のユーザーズマニュアル（CC-Link IE フィールドネットワーク Basic 編）と、GX Works3・MR Configurator2 の設定で必ず確かめてください。

## 環境と依存関係

- HTML ファイル 1 つ（`index.html`）。ライブラリは使っていません（素の JavaScript、Canvas、SVG）。
- フォントは Google Fonts から読みます。オフラインでは OS のフォントで表示され、動作は同じです。
- ブラウザの localStorage に、編集中のニーモニック、デバイスコメント、ペインの並び、ラダー図の枠の高さ、開いているタブ、コメント表示の設定、No. 指定とオーバーライドの切り替え、スイッチの位置、表示言語を保存します。ポイントテーブル・パラメータ・デバイスの値は保存しません（開き直すと初期値）。
- 実機の PLC・サーボ、GX Works3、MR Configurator2 とは通信しません。

## モデルの前提

- PLC のスキャンは 1 ms 固定。リンク周期は初期 5 ms（画面で変更可）。
- サーボの制御周期は 50 µs、検出遅れ 200 µs。位置ループ（P）→ 速度ループ（PI）→ トルクフィルタ → 電流制御（一次遅れ）。
- 機械はリード 10 mm のボールねじ、指令単位 1 µm。ストロークエンド LSN −20 mm・LSP 420 mm、近点ドグ 0〜10 mm。
- 原点復帰はドグ式・負方向で、ドグ後端を原点 0 にします（ゼロ点信号は省略）。
