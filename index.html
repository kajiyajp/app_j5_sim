回転速度 600 r/min ＝ 100 mm/s。加減速時定数は 0 から定格 3000 r/min までの時間。補助機能 1・3 は次の No. へ続けて動きます。原点復帰はドグ式・負方向で、ドグ後端（0 mm 側）を原点 0 にします（ゼロ点信号は省略）。

        


        

          
PLCリンク内容

          
GX Works3 の CC-Link IEF Basic 設定で、RWw を D2000〜、RWr を D1000〜 にリフレッシュした想定です（局番 1）。RWw・RWr とオブジェクトの対応、JOG の割り当て（コントロールワード b4/b5）、アラーム番号の形はこのシミュレータでの例です。実機は MR-J5-G のユーザーズマニュアル（CC-Link IE フィールドネットワーク Basic 編）と、サーボ・PLC の設定で必ず確かめてください。

        


        

          
    
            
  1. サンプル 1 が書込み済み・RUN で始まります。サーボ ON スイッチ（X5）が ON なので、ステータスワードが 0250h → 0231h → 0233h → 0237h と進み、サーボ ON になります。
    2. 
            
  2. JOG+（X3）を押すとモードが jg に切り替わり、押している間だけ動きます。
    3. 
            
  3. 原点復帰（X2）でモードを hm に切り替えて始動します。ドグ後端で止まり、位置実際値が 0 になります。
    4. 
            
  4. 起動（X0）でポイントテーブル No.1（300 mm）へ動きます。
    5. 
            
  5. 上のバーの「No. 指定」を「セレクタ」にすると、操作盤にデジタルスイッチ（X10〜X13、BCD）が出て、サンプル 4 が読み込まれます。スイッチで 1〜4 を選んで起動（X0）すると、その No. へ動きます。
    6. 
            
  6. ニーモニックを書き換えて「変換＋書込み」（F4 か Ctrl+Enter）。RUN 中書込みとして、そのまま動作が変わります。
    7. 
          

          
    
            
  • コントロールワードは CiA402 の状態遷移どおりに 6 → 7 → 15 と段階を踏みます。いきなり 15 を書いても ON しません（サンプル 3）。
    • 
            
  • 始動（b4）は、モード表示 6061h が切り替わったのを確かめてから立ち上げます。
    • 
            
  • 始動の受付（ステータス b12）を見たら b4 を下げ、到達（b10）で完了と判断します。
    • 
            
  • RWw・RWr はリンク周期（初期 5 ms）ごとにしか届きません。書いた次のスキャンでは、まだ結果が返っていません。タイミングチャートで b4 と b12 のずれを見られます。
    • 
            
  • ペインは左上の ⠿ をドラッグして並べ替えられます。右上のボタンで幅を変えたり、たたんだりできます。並びはこのブラウザに保存されます。

デバイスコメント（32 文字まで）

          

            
            
            
            コメントはラダー図・デバイスモニタ・タイミングチャートに出ます。このブラウザに保存されます。
          

          
        


        

          
    
            
  • 接点: LD LDI LDP LDF AND ANI ANDP ANDF OR ORI ORP ORF ANB ORB
    • 
            
  • 比較: LD= LD<> LD> LD< LD>= LD<=（AND・OR も同じ。32 ビットは LDD= など）
    • 
            
  • 出力: OUT SET RST PLS PLF、タイマ OUT T0 K10（100 ms 単位）、カウンタ OUT C0 K5
    • 
            
  • 転送・演算: MOV DMOV MOVP INC DEC + - D+ D-（P 付きは立上りで 1 回）
    • 
            
  • 変換: BIN BINP（BCD を BIN に。例 BIN K1X10 D10）
    • 
            
  • デバイス: X0〜X37 Y0〜Y37 M D T C SM400 SM402 SM412、ワードのビット指定 D1000.A（.0〜.F）
    • 
            
  • 桁指定（読み出しのみ）: K1X10＝X10〜X13 の 4 点を 1 桁として読む（K1〜K4、X・Y・M）
    • 
            
  • ; から行末はコメント。コメントだけの行は回路の上に表示（ステートメント）
